# موقع معهد كيان الأهرام للتدريب والتنمية

افتح `index.html` في المتصفح وهو الصفحة الرئيسية. مفيش حاجة تتثبّت.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `health.html` `labs.html` `survey.html` `construction.html` `business.html` `it.html` `decor.html` | صفحة لكل قسم |
| `contact.html` | التواصل: بيانات وفورم (بيفتح واتساب) وخريطة |
| `style.css` | كل التنسيق، مقسّم بأرقام في أوله |
| `script.js` | 3 حاجات بس: قائمة الموبايل، أنيميشن السكرول، زر الرجوع لأعلى |
| `images/` | `logo.png` و`favicon.png` موجودين. ضيف `hero.jpg` و`project-1.jpg` إلى `project-3.jpg` |

## ترتيب الشرح المقترح للطلاب
1. **HTML:** افتح `health.html` (أبسط صفحة): `header` و`main` و`section` و`footer` والقائمة `ul`.
2. **CSS:** غيّر `--gold` في أول `style.css` وشوف الموقع كله يتغير، وبعدها الـ flexbox في `.navbar`.
3. **الكروت:** `.departments-grid` ومتغير `--cols` (فكرة CSS variables).
4. **JavaScript:** `script.js` بالترتيب، وكل جزء مستقل.
5. **الفورم:** الكود في آخر `contact.html` (قراءة `.value` وبناء رسالة).
6. **تمرين:** أضف قسم جديد: انسخ `health.html`، وضيف كارت في `index.html`، وخيار في `contact.html`.

## الصور المطلوبة لصفحات الأقسام
الصفحة بتشتغل وتبان كويسة من غير الصور، لكن بالصور بتبقى أقوى بكتير. لكل قسم 4 صور في `images/`:

| الملف | المقاس المقترح | تظهر فين |
|---|---|---|
| `القسم-hero.jpg` | عرضية 1600×700 | خلفية أول الصفحة |
| `القسم-1.jpg` و`-2.jpg` و`-3.jpg` | 600×400 | معرض "صور من التدريب" |

أسماء الأقسام: `health` `labs` `survey` `construction` `business` `it` `decor`
مثال: `labs-hero.jpg` و`labs-1.jpg`. ابدأ بصور الهيرو السبعة.

**مهم:** الأفضل تصوير المعهد نفسه (القاعات والمعامل والطلاب بإذنهم). لو هتستخدم صور من الإنترنت، استخدم مواقع صور مجانية بترخيص واضح (Unsplash أو Pexels) وراجع الترخيص.

## بيانات تجريبية لازم تتراجع قبل النشر
- **المصروفات** `3,000 جنيه سنويًا` رقم تجريبي في الصفحات السبع. دوّر عليه وبدّله (Find and Replace).
- **فرص العمل** و**لمن هذا القسم؟** و**ماذا ستتعلم؟** نصوص عامة، عدّلها حسب الواقع.
- **مدة الدراسة**: مكتوب "من سنة إلى سنتين (غالبًا سنتان)".
